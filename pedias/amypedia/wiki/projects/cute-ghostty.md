# Cute Ghostty

Cute Ghostty is Amy's kawaii-themed wrapper/theme project for the Ghostty terminal emulator. It is cute, small, and deliberately not over-serious.

In the Amypedia worldview, Cute Ghostty matters because it represents building for fun rather than validation. Not every project needs to become a company. Some things should exist because they make the toolbench prettier.
